# Security

Please report security problems privately, not in a public issue.

Use **Report a vulnerability** on the repository's Security tab (GitHub private
vulnerability reporting). Include the Proscenium version, your macOS version and
chip, and the steps to reproduce.

In scope: the app, its update mechanism, how it reads and writes files, and
anything that could expose a writer's work.

Proscenium is maintained by one person. You will get an acknowledgement within
a week, and a fix for a confirmed problem ships as soon as it is ready.
