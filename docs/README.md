# Proscenium documentation

Proscenium is a playwriting app built around a writing surface, a binder for the
work around it, and plain files the writer owns. Start with [Product scope](app/product.md).

The app documentation follows **product area → feature → requirements and design**.
Choose an area below, then the feature you want to understand or change. These
are the detailed contracts for contributors and their coding agents. They
describe intended behavior.

## App

1. [Writing](app/writing/README.md) - script elements, dialogue, spelling, undo and comments.
2. [Organizing a play](app/organizing/README.md) - the binder, scenes, outline, materials and cast.
3. [Formatting and export](app/formatting/README.md) - page formats, opening pages, PDF and the format designer.
4. [Bringing work in](app/importing/README.md) - supported documents, import review and creating a play.
5. [Keeping your work](app/keeping-work/README.md) - files, saving, recovery, sync and privacy.
6. [Preferences and help](app/preferences-and-help/README.md) - settings, accessibility, guided practice and feedback.
